# 金陵密语 · 项目总结

> 华为开发者大赛《金陵数创·工程》参赛作品

---

## 一、项目概述

**金陵密语**是一款面向非技术用户（中学生 / 非专业大学生）的**密码学科普闯关 Web 应用**。通过 5 个递进式交互关卡，将"为什么公钥可以公开""哈希为什么不可逆""没有认证的密钥交换为什么危险"等抽象概念，转化为"亲手破解、亲眼所见"的沉浸式体验。

核心理念：**不是告诉你密码学是什么，而是让你亲手做一遍**。

## 二、核心功能

### 2.1 用户认证

| 功能 | 说明 |
|------|------|
| 注册 / 登录 | 账号 + 密码，BCrypt 哈希存储，JWT Bearer 令牌 |
| 密码策略 | 必须同时含字母和数字，且密码不能与账号相同 |
| 登录保护 | 连续失败 5 次锁定 15 分钟，防止暴力破解 |
| 角色守卫 | 前端路由 + 后端接口双层校验，管理后台额外自保护 |

### 2.2 闯关系统（5 关递进）

每关遵循统一结构：**谜面引入 → 交互解谜 → 概念总结卡 → AI 渐进提示**

| 关卡 | 名称 | 密码学概念 | 交互形式 |
|------|------|-----------|---------|
| L1 | 凯撒密码破译 | 古典密码 / 频率分析 | SVG 双环转盘拖动位移，频率柱状图辅助 |
| L2 | 哈希的不可逆 | 哈希 / 雪崩效应 / 不可逆性 | 实时 SHA-256 瀑布流 + 随机碰撞挑战 |
| L3 | 中间人攻击 | Diffie-Hellman / 身份认证 | 数据包沿通道飞行，拦截替换变红可视化 |
| L4 | 对称加密积木 | AES / 混淆与扩散 | 四步积木操作（字节替代→行移位→列混合→轮密钥加） |
| L5 | 数字签名挑战 | 哈希 + 非对称 / 防篡改 | 篡改公告前后对比验签结果 |

- **解锁链**：L1 → L2 → L3 → L4 → L5，前一关通关才能解锁下一关
- **答案校验**：全部在服务端完成（SHA-256 哈希比对），前端不暴露安全边界
- **真实算法**：哈希演示使用 Web Crypto API 的真实 SHA-256，非虚构算法

### 2.3 知识库

- 每关配套概念讲解（原理 / 为什么能被破译 / 关键步骤）
- **术语悬浮提示**：鼠标悬停术语气泡弹出解释，不跳转、不打断阅读
- **小贴士**：实用技巧与注意事项

### 2.4 答案页

- 通关后服务端判定解锁，展示本关的**解题思路 / 参考答案 / 题目解析**
- 未通关关卡显示锁定状态，不可查看

### 2.5 AI 渐进提示

- **三级递进**：L1 方向引导 → L2 方法提示 → L3 操作建议，**永不直接给答案**
- **关卡定制**：每关加载专属 `hintMaterial`，提示内容与关卡内容强相关
- **输出过滤**：OutputFilter 按关卡拦截真实答案关键词，双防线保证不泄底
- **降级开关**：AI 功能默认关闭（`ai.enabled=false`），无 AI 服务时仍可正常闯关

### 2.6 管理后台

| 功能 | 说明 |
|------|------|
| 关卡文案维护 | 在线编辑每关的 title / introText / summaryCard |
| 用户管理 | 用户列表、重置密码、锁定 / 解锁、角色切换（USER ↔ ADMIN） |
| 三层守卫 | 前端路由守卫 + 后端 JWT role 校验 + 接口自保护 |

### 2.7 进度追踪

- 登录态进度持久化，每关通关状态独立记录
- 通关解锁链自动推进

## 三、技术架构

### 3.1 技术栈

| 层 | 选型 |
|----|------|
| 前端 | Vue 3 + Vite + Pinia + TypeScript，纯 CSS（不引入 UI 框架） |
| 后端 | Java 17 + Spring Boot 3.x + Spring Data JPA |
| 数据库 | MySQL 8.x |
| 认证 | Spring Security + JWT Bearer（BCrypt） |
| AI | 华为云 MaaS / 盘古主通道，对话网关防腐层 |
| 部署 | 华为云 ECS + Nginx + Docker |
| 接口文档 | springdoc-openapi（Swagger UI） |

### 3.2 后端分层

```
api/v1/          控制器层 — 协议转换 + 校验
service/         服务层 — 业务逻辑
dialogue_gateway/ 防腐层 — AI 唯一出口（MAAS 主 / MADAO 留痕 / FALLBACK 备份）
model/entity/    JPA 实体
model/repo/      Spring Data JPA 仓库
security/        JWT 过滤器与工具
common/          通用工具与异常处理
config/          安全配置与数据初始化
```

依赖方向：`api → service → {model, dialogue_gateway, security}`，禁止环形依赖。

### 3.3 前端组件体系

**21 个自研组件**，分为三类：

**交互关卡组件**（5 个）：
- `CaesarPuzzle` — SVG 双环转盘，拖动外环位移解密
- `HashCollisionPuzzle` — 实时哈希瀑布流 + 随机碰撞
- `MitmPuzzle` — 数据包飞行通道 + 拦截替换
- `AesBlocksPuzzle` — 四步积木操作演示
- `SignaturePuzzle` — 篡改对比验签

**视觉增强组件**（8 个）：
- `HexRain` — 十六进制字符雨 Canvas 背景
- `GlitchText` — 故障风文字效果
- `TypeWriter` — 逐字打字机效果
- `CipherConfetti` — 通关密文粒子庆祝
- `CipherSkeleton` — 密文风格骨架屏加载
- `ProgressRing` — SVG 环形进度
- `RollingNumber` — 数字滚动效果
- `TiltCard` — 3D 倾斜卡片 + 光晕

**功能组件**（8 个）：
- `PasswordInput` — 密码输入（含小眼睛切换）
- `TermTip` — 术语悬浮提示
- `ToastHost` — 全局消息提示
- `ConceptCard` — 概念总结卡
- `HintDialog` — AI 提示对话框
- `FrequencyChart` — 频率分析柱状图
- `DhTimeline` — DH 协商时间轴
- `HashSearchAnimation` — 哈希搜索动画

### 3.4 数据驱动

- **关卡配置**：`resources/data/levels.json` 驱动（谜面 / 答案哈希 / 解锁链 / AI 提示素材）
- **知识库**：`resources/data/knowledge.json` 驱动（概念讲解 / 解题步骤 / 参考答案 / 解析）
- 新增 / 修改关卡只需编辑 JSON，无需改代码

## 四、视觉与交互设计

### 4.1 设计语言

**「密码学符码风」暗色终端主题**

- 深青灰基色调（`#0a1628` → `#1a2a4a`），搭配荧光绿（`#00ff88`）与琥珀色（`#ffaa00`）点缀
- 背景光晕呼吸动效 + CRT 扫描线叠加
- 所有动效均支持 `prefers-reduced-motion` 媒体查询，尊重用户偏好

### 4.2 交互亮点

- 页面切换过渡（fade + slide）
- 关卡卡片 3D 倾斜跟随鼠标 + 悬停光晕
- 通关后密文粒子庆祝动画
- 数据加载骨架屏（密文风格）
- 标题 glitch 故障效果
- 打字机逐字呈现

## 五、启动与部署

### 5.1 一键启动

```
run.bat    → Java 驱动启动器（Launcher.java）
```

- 自动拉起 Spring Boot 后端 + Vite 前端
- 日志写入 `logs/` 目录（backend.log / frontend.log）
- 启动前自动清理上次残留进程（直接关窗口也不会端口占用）
- 自动打开浏览器访问 `http://localhost:5173`
- 按回车优雅退出

### 5.2 自包含环境

- `.tools/` 内置 JDK 17 + Maven 3.8.8，无需用户手动安装
- 首次运行自动 `npm install` 前端依赖

### 5.3 生产部署

- `deploy/` 目录提供 `docker-compose.yml` + Nginx 配置
- 华为云 ECS（c7.large.2）+ Nginx 反向代理 + OBS 静态资源

## 六、安全设计

| 措施 | 说明 |
|------|------|
| 密码存储 | BCrypt 哈希，不可逆 |
| 认证令牌 | JWT Bearer，无 Cookie |
| 接口保护 | Spring Security 过滤器链，角色级访问控制 |
| 答案校验 | 服务端 SHA-256 哈希比对，前端不暴露答案 |
| AI 防泄底 | 提示词模板 + OutputFilter 后置过滤双防线 |
| 登录保护 | 5 次失败锁定 15 分钟 |
| 管理后台 | 三层守卫（路由 / JWT role / 接口自保护） |

## 九、总结

金陵密语通过**可视化交互 + 渐进式引导 + AI 辅助**，让密码学从抽象理论变成可触摸的体验。5 关递进覆盖古典密码 → 哈希 → 密钥交换 → 对称加密 → 数字签名，形成完整的密码学认知链路。

技术层面采用前后端分离架构，后端分层清晰、AI 防腐层隔离外部依赖；前端纯 CSS 实现全部动效，21 个自研组件覆盖交互与视觉需求。一键启动器降低使用门槛，自包含环境无需额外安装。
